Theorem. Assume \(\gamma\in(0,1)\), finite state and action spaces, and bounded rewards. Then the optimal value function \(V^*\) exists and satisfies the Bellman optimality equation:

\[ V^*(s)=\max_{a\in\mathcal A} \mathbb E_{(r,s')\sim p(\cdot\mid s,a)} \left[r+\gamma V^*(s')\right]. \]
Proof

Define the Bellman optimality operator \(T^*\). It is a strict contraction with respect to the sup norm:

\[ \lVert T^*V_1-T^*V_2\rVert_\infty \leq\gamma\lVert V_1-V_2\rVert_\infty. \]

Therefore \(T^*\) has a unique fixed point. A policy greedy with respect to that fixed point realizes the same value and is optimal.
